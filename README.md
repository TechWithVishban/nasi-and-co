# Nasi & Co. — Malaysian Restaurant Website

A modern, responsive restaurant website concept showcasing Malaysian comfort food through a clean layout, elegant typography and a warm visual identity.

**Live Demo**: https://techwithvishban.github.io/nasi-and-co/

## About the Project

Nasi & Co. is a fictional Malaysian restaurant brand created as a front-end web development and digital design portfolio project.

The website aims to present a restaurant's identity, signature dishes, menu and contact information in a simple and accessible way.

## Features

- Responsive layout for desktop, tablet and mobile devices
- Mobile navigation menu with interactive toggle
- Hero section with restaurant branding
- Signature dish showcase with food photography
- Categorised food and beverage menu with prices
- About section introducing the restaurant concept
- Contact section with a WhatsApp enquiry button (demo placeholder)
- Consistent brand colours and typography

## Technologies Used

- **HTML5** — Website structure and semantic content
- **CSS3** — Layout, styling and responsive design
- **JavaScript** — Interactive mobile navigation
- **Canva Pro** — Brand identity and menu design
- **GitHub Pages** — Website hosting and deployment

## Brand Identity
